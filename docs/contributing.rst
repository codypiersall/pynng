Contributing
============

We welcome contributions to pynng! Whether you want to fix a bug, improve performance,
expand transport support, or improve documentation, we would love your help.

Please see our comprehensive `Contributing Guide (CONTRIBUTING.md) <https://github.com/codypiersall/pynng/blob/master/CONTRIBUTING.md>`_
on GitHub for full details:

* **Where to Start**: Browsing open `GitHub Issues <https://github.com/codypiersall/pynng/issues>`_ (labeled ``good first issue`` or ``help wanted``) and the `Project Roadmap <https://github.com/codypiersall/pynng/blob/master/ROADMAP.md>`_
* **Development Setup**: Prerequisites (Python 3.10+, CMake 3.26+, ninja, libclang), installation with ``uv``, and pre-commit configuration
* **Accelerating Builds**: Setting up ``sccache`` for near-instant local C compilation and caching CMake dependencies
* **Testing**: Running pytest, asyncio/trio test suites, and testing against free-threaded Python (PEP 703)
* **Code Style & CI Workflows**: Ruff formatting, changelog updates, and CI matrix explanations
* **Native Debugging**: Stepping through native C extensions and NNG libraries using lldb or gdb
